**Brief description of each solution:**

**Exercise 1:** This exercise construct a SocialGraph using both an adjacency matrix and an adjacency list for graph representation. It supports fundamental operations such as adding and removing friendships, as well as checking for existing connections. It also includes methods to calculate key graph metrics like density, degree distribution, and to verify if the graph is complete.

**Exercise 2:** This exercise extends the SocialGraph class with Depth-First Search (DFS) algorithms for graph traversal and analysis. It implements both recursive and iterative DFS traversal, connected components detection, graph connectivity verification, and path existence checking between users in the social network.

**Exercise 3:** This exercise expands the SocialGraph class with Breadth-First Search (BFS) algorithms for efficient graph exploration. It supports BFS traversal, shortest path finding between users, distance calculation in the social network, and level-based neighbor discovery for social connection analysis.
