**Brief description of each solution:**

Exercise 1: Exercise 1 models an event invitation scenario as a Maximum Independent Set problem to find the largest group of attendees without personal conflicts. It requires implementing an exact backtracking algorithm with pruning and comparing its performance against a faster greedy heuristic.

Exercise 2: Exercise 2 is about choosing the best users to send a message to so that the total reach is as large as possible without going over the budget.

Exercise 3: Implement a balanced partition algorithm to split social network users into two groups while minimizing cross-group friendships and satisfying a 40% minimum size constraint. It also involves designing a greedy heuristic and a local search strategy, and analyzing the graph structure, algorithm behavior, and computational performance.
